## FAQ

**Q: Is 121XQ a different product than 121AI?**  
A: No—same product, clearer positioning. 121AI → 121XQ is a brand refinement to emphasize execution focus.

**Q: Does my system need to change?**  
A: No. Existing deployments continue running. New UI and branding available at 121xq.com.

**Q: What's the difference between 121XML and 121XQ?**

A: Because "AI" is marketing noise. XQ = execution coefficient—it measures intelligent delivery of results.

**Q: Is this an API change?**
