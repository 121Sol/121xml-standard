Core Endpoints

1. Query Endpoint

POST /api/v1/query

Send a query to the orchestration engine for routing to optimal AI system

Request

POST /api/v1/query HTTP/1.1
Host: api.121xml.us
Content-Type: application/json
Authorization: Bearer YOUR_API_KEY

{
  "content": "What is 121XML?",
  "model_preference": "auto",
  "temperature": 0.7,
  "max_tokens": 4096,
  "system_prompt": "You are helpful..."
}

Response (200 OK)

{
  "_type": "response",
  "_schema": "urn:121xml:response/1.0",
  "content": "121XML is a universal AI orchestration platform...",
  "model_used": "claude",
  "tokens_used": 150,
  "_address": "data://sha256:abc123:response",
  "cost": "$0.05"
}

2. Convert Endpoint

POST /api/v1/convert

Convert between any two formats (SWIFT, ISO20022, JSON, etc.)

Request

POST /api/v1/convert HTTP/1.1
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "input_format": "swift",
  "output_format": "iso20022",
  "data": "SWIFT_MESSAGE_HERE",
  "validate": true
}

3. Archive Endpoint

POST /api/v1/archive

Store data with immutable SHA256 content addressing

Response includes:

{
  "_address": "data://sha256:hash:type",
  "retrieval_time_ms": 50,
  "compression_ratio": 0.94
}
