================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "Permission Denied" during upload
FIX:
  - Use Method 2 (File Manager) instead
  - Or check SSH credentials

PROBLEM: Website shows blank page
FIX:
  - Verify index.html exists (use File Manager)
  - Check file size (~50 KB)
  - Check permissions (644)

PROBLEM: Can't connect via SSH/FTP
FIX:
  - Verify credentials are correct
  - Try Method 2 (File Manager, no SSH needed)

PROBLEM: HTTPS shows certificate warning
FIX:
  - Wait 30 minutes (AutoSSL generates certificate)
  - Then refresh browser
  - Force refresh: Ctrl+Shift+R

PROBLEM: Domain not resolving
FIX:
  - Check DNS settings point to hosting121.com
  - May take 24 hours to propagate
  - Try: nslookup 121xml.com
