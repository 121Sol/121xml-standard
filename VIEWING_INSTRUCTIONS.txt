TROUBLESHOOTING:

Problem: HTML file won't open
Solution: Right-click → Open with → Select web browser (Chrome, Firefox, etc.)

Problem: Diagrams not showing
Solution: Ensure JavaScript is enabled (usually default)
         Try different browser if issue persists

Problem: Text is too small
Solution: Use Ctrl++ to zoom in (Ctrl+- to zoom out)
         Or pinch on mobile to zoom

Problem: Printing has issues
Solution: Try "Landscape" orientation
         Adjust margins in print dialog
         Preview before printing
