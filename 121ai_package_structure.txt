PLATFORM SUPPORT MATRIX:
========================

| Platform        | Method              | Runtime      | Package Type  |
|-----------------|---------------------|--------------|---------------|
| **Web**         | FastAPI + React     | Python       | .whl, Docker  |
| **Windows**     | PyInstaller         | Bundled CPython | .exe, .msi  |
| **macOS**       | PyInstaller + Codesign | Bundled CPython | .dmg, .pkg |
| **Linux**       | PyInstaller         | Bundled CPython | .AppImage   |
| **iOS**         | BeeWare/PyObjC      | Native iOS   | .ipa, Testflight|
| **Android**     | Kivy + Buildozer    | Python-for-Android | .apk      |
| **Google Devices** | Google Assistant integration | Python | Backend API |
| **Docker**      | Containerized       | Python       | Docker Image  |
| **Kubernetes**  | Helm Chart          | Python       | K8s Pod       |

DEPENDENCY SUMMARY:
===================

- fastapi >= 0.95.0            (Web framework)
- pydantic >= 2.0              (Data validation)
- sqlalchemy >= 2.0            (Database ORM)
- aiohttp >= 3.8               (Async HTTP)

AI/ML Dependencies:
- openai >= 1.0                (OpenAI API)
- anthropic >= 0.7             (Anthropic API)
- google-generativeai >= 0.3   (Google AI)

Mobile/Desktop Dependencies:
- kivy >= 2.1                  (Mobile UI)

Monitoring/Security Dependencies:

Testing Dependencies:

Development Dependencies:

BUILD & DEPLOY:
===============

Build for Windows:
  pyinstaller --onefile --windowed 121ai/__main__.py -o dist/121AI.exe

Build for macOS:
  pyinstaller --onefile --windowed 121ai/__main__.py -o dist/121AI.app

Build for Linux:
  pyinstaller --onefile 121ai/__main__.py -o dist/121AI

Build Docker image:
  docker build -t 121ai:latest .

Build Python wheel:
  python -m build

Build iOS (requires macOS + Xcode):
  briefcase build ios
  briefcase package ios

Build Android (requires Android SDK):
  buildozer android debug
