IF SOMETHING GOES WRONG
───────────────────────

Can't connect:
  → Use Option B (File Manager) - no SSH needed
  → Check FTP credentials
  → Contact HostArmada support

Website shows blank:
  → Check index.html exists in public_html
  → Check file size (~50 KB)
  → Check permissions (should be 644)

HTTPS certificate error:
  → Normal - wait 30 minutes
  → AutoSSL generates certificate
  → Refresh browser after 30 min
  → Or manually run AutoSSL in cPanel

Domain not found:
  → Check DNS points to hosting121.com
  → May take 24 hours to propagate
  → Contact domain registrar
