## 2. LOGO & WORDMARK

### Logo Description

The 121AI logo represents the core concept of "1-to-1" connectivity with an AI intelligence element:

**Visual Elements:**
- **Three Connected Nodes** – Left node (1), center node (2 - larger, glowing), right node (1)
- **Connecting Paths** – Curved lines with gradient glow suggesting energy and flow
- **Circuit Elements** – Small decorative circuit patterns within center node suggesting AI
- **Color Gradient** – Navy to Teal gradient suggesting enterprise-grade innovation

**Symbolism:**
- **"1-2-1" Pattern** – Represents universal translation (converting from any source to any destination)
- **Center Glow** – Represents AI intelligence at core
- **Connected Nodes** – Represents interconnected systems
- **Gradient** – Represents progression from traditional (navy) to future (teal)

### Logo Variations

**Primary Logo** (Full Color)
- Use in most contexts
- Background: Light or white
- Minimum size: 40px width
- File: 121AI_LOGO.svg

**Monochrome Logo** (Dark Navy)
- Use on white/light backgrounds
- Use in black & white printing
- Use when color not available
- Maintains full detail at any size

**Monochrome Logo** (White)
- Use on dark backgrounds
- Use on brand color backgrounds
- Use in dark-themed interfaces

**Icon Only**
- Use in favicons (16x16, 32x32, 64x64 px)
- Use in app icons
- Use as social media profile pictures
- Background must have sufficient contrast

**Horizontal Lockup** (Logo + Wordmark)
- Logo on left, "121AI" wordmark on right
- 20px minimum spacing between
- Use in headers, presentations, documents

**Vertical Lockup** (Logo above Wordmark)
- Logo centered above "121AI" wordmark
- Use in narrow spaces (sidebars, business cards)
- Maintain 20px spacing

### Logo Clear Space

**Minimum Clear Space:** 20px on all sides (at 40px logo width)

The clear space is defined as 20px of empty space around the logo. Nothing should intrude into this space:
- No text
- No graphics
- No background patterns
- No borders

### Logo Sizing

**Minimum Size:**
- Digital (web/screen): 40px width
- Print (300 DPI): 0.4 inches width
- Presentation slides: 0.5 inches width

**Maximum Size:**
- No maximum size (maintain aspect ratio)
- Logo should never be pixelated (use vector SVG)

### Logo Files

**Provided Files:**
- `121AI_LOGO.svg` – Primary full-color logo
- `121AI_LOGO_MONOCHROME_DARK.svg` – Dark navy version
- `121AI_LOGO_MONOCHROME_WHITE.svg` – White version
- `121AI_LOGO_ICON.svg` – Icon only (no wordmark)

**File Format Requirements:**
- Primary: SVG (scalable vector)
- Backup: PNG at 2x resolution (transparent background)
- Never: Use JPG, GIF, or low-res versions

### Wordmark

**Font:** Use "121AI" in title case  
**Style:** Bold, letter-spacing: 2px  
**Color:** Primary navy (#0A2463)  
**Size:** Proportional to logo (typically 1:1 ratio with logo height)

## 3. COLOR PALETTE

- Hex: #0A2463
- RGB: 10, 36, 99
- CMYK: 90, 64, 0, 61
- PMS: 281C
- Use: Primary backgrounds, headings, navigation
- Psychology: Trust, stability, corporate, professional

**Secondary Teal**
- Hex: #06D6A0
- RGB: 6, 214, 160
- CMYK: 97, 0, 25, 16
- PMS: 16-1546 TCX
- Use: Accents, CTAs, highlights, active states
- Psychology: Innovation, forward-thinking, energy, growth

### Accent Color

**Warm Gold**
- Hex: #F39C12
- RGB: 243, 156, 18
- CMYK: 0, 36, 93, 5
- PMS: 144C
- Use: Alerts, achievements, premium features
- Psychology: Excellence, value, premium quality

### Neutral Colors

**Light Gray** (Background)
- Hex: #F5F7FA
- RGB: 245, 247, 250
- CMYK: 2, 1, 0, 2
- Use: Section backgrounds, card backgrounds

**Medium Gray** (Borders)
- Hex: #E0E6ED
- RGB: 224, 230, 237
- CMYK: 6, 3, 0, 7
- Use: Borders, dividers, separators

**Dark Gray** (Text)
- Hex: #2C3E50
- RGB: 44, 62, 80
- CMYK: 45, 23, 0, 69
- Use: Body text, primary text

**Light Text Gray**
- Hex: #5D6D7B
- RGB: 93, 109, 123
- CMYK: 24, 11, 0, 52
- Use: Secondary text, captions, descriptions

**White**
- Hex: #FFFFFF
- RGB: 255, 255, 255
- CMYK: 0, 0, 0, 0
- Use: Backgrounds, text on dark backgrounds

### Color Usage Rules

**Do:**
✓ Use navy (#0A2463) for primary sections and headings
✓ Use teal (#06D6A0) for CTAs and interactive elements
✓ Use gold (#F39C12) sparingly for highlights
✓ Ensure sufficient contrast (WCAG AA minimum 4.5:1 for text)
✓ Use neutrals for backgrounds and secondary content

**Don't:**
✗ Use navy and teal at full opacity together (creates visual clash)
✗ Use navy text on teal backgrounds (low contrast)
✗ Invent new colors (stick to palette)
✗ Use gradients without approval (use pre-approved gradients only)

### Color Combinations

**Primary Gradient** (Use for CTAs, headers)
- Start: #0A2463 (navy)
- End: #06D6A0 (teal)
- Direction: 135deg (diagonal)
- Example: `background: linear-gradient(135deg, #0A2463 0%, #06D6A0 100%);`

**Secondary Gradient** (Use for highlights, decorative)
- Start: #06D6A0 (teal)
- End: #F39C12 (gold)
- Direction: 135deg
- Example: `background: linear-gradient(135deg, #06D6A0 0%, #F39C12 100%);`

**Shadow Color**
- Navy with 10-15% opacity
- Example: `box-shadow: 0 4px 20px rgba(10, 36, 99, 0.1);`

### Accessibility

**Text Color Requirements:**
- Navy text on white: 7.7:1 contrast (WCAG AAA)
- Navy text on light gray: 5.2:1 contrast (WCAG AA)
- Teal text on white: 4.8:1 contrast (WCAG AA)
- Gold text on white: 6.8:1 contrast (WCAG AA)
- White text on navy: 8.2:1 contrast (WCAG AAA)
- White text on teal: 5.9:1 contrast (WCAG AA)

**Color Blindness:**
- Avoid navy + maroon combinations (red-colorblind friendly)
- Avoid teal + gray combinations (green-colorblind friendly)
- Always use patterns, icons, or text in addition to color

## 4. TYPOGRAPHY

### Font Families

**Primary Font: Segoe UI**
- Family: Segoe UI (sans-serif)
- Fallback: Arial, Helvetica, sans-serif
- License: System font (included with Windows, Mac, modern browsers)
- Use: All body text, UI elements
- Weights: 400 (Regular), 600 (Semibold), 700 (Bold), 800 (Extra Bold)

**Heading Font: Segoe UI Bold**
- Font: Segoe UI
- Weight: 700-800
- Style: Uppercase preferred for major headings
- Letter-spacing: -0.5px to -1px (for visual appeal)

### Type Scale

**H1 – Main Heading**
- Font-size: 52px (desktop) / 36px (mobile)
- Font-weight: 800
- Letter-spacing: -1px
- Line-height: 1.2
- Use: Hero section headings, page titles
- Color: #0A2463 (navy) or white on dark background

**H2 – Section Heading**
- Font-size: 40px (desktop) / 28px (mobile)
- Font-weight: 800
- Letter-spacing: -0.5px
- Line-height: 1.2
- Use: Major section headings
- Color: #0A2463 (navy)

**H3 – Subsection Heading**
- Font-size: 20px
- Font-weight: 700
- Letter-spacing: 0px
- Line-height: 1.4
- Use: Card headings, subsection titles
- Color: #0A2463 (navy)

**H4 – Small Heading**
- Font-size: 18px
- Font-weight: 700
- Letter-spacing: 0px
- Line-height: 1.4
- Use: UI component headings
- Color: #0A2463 (navy)

**Body Text**
- Font-size: 16px
- Font-weight: 400
- Line-height: 1.6 (27px)
- Use: Paragraphs, main content
- Color: #2C3E50 (dark charcoal)

**Caption / Small Text**
- Font-size: 13px
- Font-weight: 400
- Line-height: 1.5
- Use: Figure captions, labels, metadata
- Color: #5D6D7B (light gray)

**Label / UI Text**
- Font-size: 14px
- Font-weight: 600
- Text-transform: uppercase
- Letter-spacing: 0.5px
- Use: Button labels, form labels, badges
- Color: #0A2463 (navy)

### Font Pairing

The 121AI brand uses a single font family (Segoe UI) in different weights and sizes. This provides:
- Professional appearance
- Excellent readability
- Consistent visual language
- System efficiency (no extra font downloads needed)

### Typography Do's & Don'ts

**Do:**
✓ Use Segoe UI or system sans-serif fallback
✓ Maintain generous line-height (1.5+) for readability
✓ Use uppercase sparingly (headings, labels only)
✓ Pair bold headings with light body text
✓ Use letter-spacing to create visual interest in headings

**Don't:**
✗ Use decorative or script fonts
✗ Use serif fonts (except for quotes/testimonials)
✗ Render text as images
✗ Use all-caps for body text
✗ Decrease line-height below 1.4

## 5. IMAGERY & GRAPHICS

### Photography Style

**General Principles:**
- Professional, not candid (business-focused)
- Well-lit (bright, high contrast)
- Authentic but polished (no overly staged photos)
- Diverse representation (people, not stock photos with obvious bias)
- Modern, clean backgrounds

**Recommended Subjects:**
- Enterprise office environments
- Diverse teams in tech/business settings
- Data visualization dashboards
- Network/connection imagery
- Technology infrastructure (servers, code, etc.)

**Avoid:**
- Overly staged or artificial photos
- Outdated or worn technology
- Generic stock photos (people in awkward poses)
- Dark or low-contrast images
- Photos with logos of competitors

### Icon Style

**Icon Characteristics:**
- Outline style (not filled)
- Consistent stroke weight (1.5-2px)
- Simple, recognizable shapes
- Scalable to all sizes
- Color: Navy (#0A2463) or white on dark backgrounds

**Icon Grid:**
- 24x24px base grid
- 4px padding on all sides
- Snap to grid (no diagonal lines unless necessary)
- Consistent 2px corner radius on squared shapes

**Icon Usage:**
- Use for features, benefits, problems
- Size proportionally (don't make too small)
- Pair with text labels
- Use solid colors (no gradients on icons)

**Icon Library:**
- Create custom icon set (not using generic libraries)
- Document all icons with SVG code
- Version control for consistency

### Graphic Elements

**Dividers**
- Use thin lines (1px) in light gray (#E0E6ED)
- Add subtle gradient for visual interest
- 20-40px spacing above/below

**Cards & Containers**
- 12px border-radius for rounded corners
- Box-shadow: 0 4px 20px rgba(10, 36, 99, 0.1)
- On hover: Box-shadow: 0 12px 40px rgba(10, 36, 99, 0.15)
- Background: White (#FFFFFF) or light gray (#F5F7FA)

**Badges & Labels**
- 6px border-radius (smaller than cards)
- Padding: 8px 12px
- Font: 13px bold, uppercase, letter-spacing: 0.5px
- Colors: Navy text on light gray background, or white text on navy background

**Decorative Elements**
- Circles: Use in hero sections, backgrounds
- Gradients: Use navy-to-teal gradient for visual interest
- Blur effects: Use subtly for depth (backdrop-filter: blur(5px))

## 6. TONE & VOICE

### Brand Voice

The 121AI voice is professional, confident, and approachable. We speak to enterprise audiences about serious topics, but in language they can understand and relate to.

### Tone Principles

**Professional Yet Approachable**
- Use clear, direct language
- Avoid jargon unless necessary (explain technical terms)
- Use contractions (we're, don't, can't) to be conversational
- Address the reader directly (you, your)

**Confident Without Arrogance**
- State facts clearly (we're the only platform that...)
- Support claims with evidence (with data, case studies)
- Acknowledge limitations when relevant
- Focus on customer outcomes, not our features

**Empathetic & Customer-Focused**
- Acknowledge customer pain points and frustrations
- Show we understand their challenges
- Center solutions around their needs
- Use success stories and testimonials

### Tone for Different Contexts

**Marketing Copy**
- Benefit-focused (what problems does this solve?)
- Results-oriented (what will customers achieve?)
- Active voice (we deliver results, not results are delivered)
- Confident and direct

**Example:** "121AI eliminates vendor lock-in. Switch between Claude, GPT, and Gemini without rewriting your code."

**Customer Support**
- Helpful and patient
- Assume customer is not technical (explain things clearly)
- Empathetic (acknowledge frustration)
- Action-oriented (provide clear next steps)

**Example:** "We understand this is frustrating. Here's exactly how to resolve it in 3 steps..."

**Product Documentation**
- Clear and structured
- Step-by-step (numbered lists)
- Use examples liberally
- Anticipate questions and answer preemptively

**Example:** "To convert SWIFT to JSON: 1) Upload your SWIFT file. 2) Select JSON as target format. 3) Click Convert. Done!"

**Social Media**
- Conversational and engaging
- Celebrate wins (customer stories, metrics)
- Admit mistakes and fixes transparently
- Respond with personality (not robotic)

**Example:** "🎉 Just shipped content addressing explorer. You can now prove data integrity with SHA256 hashes. Check it out →"

### Key Messaging Framework

**Problem Statement:**
- Enterprise AI vendors create lock-in
- Data formats create silos
- Switching costs are astronomical

**Positioning:**
- 121AI is the universal orchestration layer
- We eliminate vendor lock-in
- We enable complete data portability

**Proof Points:**
- 0% data loss guarantee
- 94% token compression
- 2-hour deployment
- 99.95% uptime SLA

**Call to Action:**
- Try it free (developer tier)
- Schedule a demo
- Read the docs

### Messaging by Audience

**Enterprise (CTO/VP Infrastructure)**
- Focus: Reliability, compliance, control
- Message: "Reduce AI costs 40%. Deploy on-prem. Control your keys."
- Proof: SLA, HIPAA/GDPR compliance, case studies

**Mid-Market (VP Technology)**
- Focus: Speed to market, cost, flexibility
- Message: "Deploy in 2 hours. Switch vendors anytime. Reduce costs 40%."
- Proof: ROI calculator, quick-start guide, customer testimonials

**Developers (Solo/Small Team)**
- Focus: Developer experience, freedom, no vendor lock-in
- Message: "Build with any AI system. Never get locked in. Ship faster."
- Proof: GitHub stars, documentation, community projects

**CFO (Financial Decision-Maker)**
- Focus: Cost savings, ROI, long-term value
- Message: "Reduce AI infrastructure costs 40%. Predict spend in real-time. ROI in 6 months."
- Proof: Cost calculator, case study ROI breakdown, comparison analysis

## 7. USAGE GUIDELINES

### Logo Placement

**Website Header**
- Place logo in top-left corner
- Use horizontal lockup (logo + wordmark)
- Minimum 40px height
- Link to homepage
- Add navigation menu to right

**Social Media**
- Use icon-only logo (40x40px to 128x128px)
- Upload as square image (transparent background)
- For profile picture, use icon on navy background

**Email Signature**
- Use horizontal lockup (logo + wordmark)
- Height: 40-50px
- Place in footer with company details

**Business Cards**
- Logo in top-left or center
- Size: 0.5" x 0.5"
- Use primary or monochrome version (color may not print well)

**Presentation Slides**
- Use horizontal lockup in presentation header
- Size: proportional (typically 0.5-0.75 inches)
- Place in consistent location (top-left recommended)

**Documents & Reports**
- Use horizontal lockup on title page
- Size: 1-1.5 inches width
- Can use in footer on subsequent pages (smaller, 0.5")

### Color Application

**Primary Navy (#0A2463)**
- Use for: Main headings, navigation backgrounds, CTAs
- Coverage: Should be 60-70% of primary brand colors
- Prominence: Most prominent color

**Secondary Teal (#06D6A0)**
- Use for: Interactive elements, accents, secondary CTAs
- Coverage: Should be 20-30% of primary brand colors
- Prominence: Second most prominent

**Accent Gold (#F39C12)**
- Use for: Highlights, alerts, premium features
- Coverage: Should be 5-10% of primary brand colors
- Prominence: Used sparingly for emphasis

**Neutral Colors**
- Use for: Backgrounds, text, borders
- Coverage: Should be 30-40% overall
- Prominence: Provides breathing room

### Material Guidelines

**Digital Materials (Web, Email, Social)**
- Use RGB colors (#0A2463, #06D6A0, #F39C12)
- Use SVG for logo (scales perfectly)
- Ensure 4.5:1 minimum contrast for text
- Test on multiple devices/browsers

**Print Materials (Business Cards, Brochures, Posters)**
- Use CMYK colors (see color palette)
- Use PMS for spot color printing
- Minimum resolution: 300 DPI
- Use PNG backup if SVG not supported

**Video & Motion**
- Use primary gradient for animated backgrounds
- Animate logo entrance (fade in or slide from left)
- Use brand colors consistently
- Ensure text has sufficient contrast over video
